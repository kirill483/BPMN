# BPMN

## О проекте

Данная BPMN-диаграмма представляет собой учебную модель бизнес-процесса доставки продуктов из магазина.

Диаграмма описывает основной сценарий выполнения заказа: оформление заказа клиентом, проверку наличия товаров, их резервирование, оплату, сборку заказа на складе, назначение курьера и доставку клиенту.

**Упрощения модели:**
- Не рассматриваются технические детали взаимодействия с платёжными системами.
- Не моделируются ошибки оплаты и их обработка.
- Не рассматриваются возвраты денежных средств и обработка претензий клиентов.
- Не моделируются ситуации, связанные с опозданием курьера и другими исключительными обстоятельствами.

Цель проекта — продемонстрировать применение нотации BPMN для моделирования основного бизнес-процесса, а не описать все возможные сценарии работы реального сервиса доставки.
